# Bach Chorale Harmony

Interactive Roman-numeral analysis and playback of Bach chorales.

- Scores: music21 corpus, with corrections noted in the analysis script
- Analysis: generated with music21 (key finding, beat-level Roman numerals, applied chords, suspensions)
- Notation: OpenSheetMusicDisplay; playback: Tone.js
- Instrument samples: FluidR3 GM and FatBoy General MIDI soundfonts (via midi-js-soundfonts)
- Titles: bach-chorales.com and Bach Digital
